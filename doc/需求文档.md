# 起因
因为有些人做完手术后,无法说话,因此想开发一款APP用于日常对话

# 设计要求
1. 界面简单,打开后界面类似九宫格
2. 老年人视力不好,需要字体尽可能大,对比度尽可能高
2. 界面上有简单的提示词,点击提示词后刷新显示关联的提示词
3. 点击提示词后,上方显示拼接后的句子,,右侧为发音按钮,点击阅读输入的文字
4. 九宫格按钮中,第三排按钮应该为:清空,上一页,下一页
5. 点击的按钮为提示词,并不一定就是用户具体想说的话
6. 需要整合衣食住行
7. 可能需要多平台,如安卓端,微信小程序
8. 减少不必要的权限申请

# 举例
1. 当用户想脱衣服,,,用户依次点击  我-->衣->-->脱下+ok  显示:我脱衣服
2. 更多可能的点击   你-->食-->吃->饭  显示  你吃饭
3. 我-->住-->睡觉  显示 我要睡觉

## 当前实现范围（2026-11-03）

以下内容是这份需求文档对应的当前落地版本，后续改动以根目录 <code>README.md</code>、<code>AGENTS.md</code>、<code>js/data.js</code> 和 <code>js/core.js</code> 为准。

### 已覆盖场景

- **常用表达**：11 页、66 条整句，覆盖紧急求助、基本需求、如厕护理、身体不适、疼痛位置、照护、回答、感受、医疗、社交、家人。
- **组合表达**：人物 → 类别 → 项目/子分类 → 动作；支持医疗检查、治疗、用药、护理、住院等子分类。
- **身体与感受**：18 个身体部位及疼痛/酸/麻/痒/肿等状态；害怕、难过、焦虑、孤独、生气、累、冷、热、想家等感受。
- **照护操作**：穿衣、吃饭、居住环境、行动、翻身、拍背、如厕、洗漱、轮椅、拐杖等。
- **辅助功能**：语音朗读、语速/语音选择、自动朗读、历史记录、自定义常用语、字体/主题/高对比、震动、屏幕常亮、全屏、键盘操作。
- **离线与安装**：PWA Manifest、Service Worker 缓存，可添加到主屏幕离线使用。

### 交互约定调整

- 继续使用 3×3 九宫格：6 个内容按钮 + 3 个功能按钮。
- 第三行固定为“清空 / 上一页 / 下一页”；返回上一级放在顶部路径栏，避免占用九宫格位置。
- 常用表达点一下即完成并朗读；组合表达在动作或“直接说出”项目完成后朗读。
- 所有历史记录、自定义常用语和设置只保存在本机浏览器，不上传服务器。

### 暂不包含

- 原生 Android / iOS 安装包。
- 云端账号、跨设备同步、远程词板管理。
- 图片符号词板、照顾者可视化编辑器。
- 医疗诊断、分诊或任何替代医护判断的能力。
